# Julio Roja — Consultor en IA y automatización

Sitio de marca personal ([julioroja.dev.ar](https://julioroja.dev.ar)). Next 16, React 19, TypeScript y Tailwind 4.

## Desarrollo

```bash
cp .env.example .env.local   # completar NEXT_PUBLIC_WHATSAPP_NUMBER
npm install
npm run dev
```

Otros comandos: `npm run build`, `npm run lint`, `npm run typecheck`.

El contenido (servicios, FAQs, datos de contacto) vive en `src/data/`. Ver `CLAUDE.md` para la arquitectura.
